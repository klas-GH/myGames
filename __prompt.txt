Build a polished mobile-first mini-game arcade app containing exactly 8 small games.

Core concept

The app is a simple, fast, fun arcade where the user opens the app and sees 8 large game icons/cards. Each card launches its own independent mini-game screen.

The experience should feel like one cohesive app, not 8 unrelated games.

Prioritize:

Mobile-first UX
Fast loading
Simple controls
Short game sessions
Smooth animations
Responsive layout
Clean, modern UI
Touch-friendly buttons
Consistent navigation
Local high scores/progress where appropriate

Shared UI / UX

Every game should have:

Back button → returns to Arcade home
Consistent top navigation
Game title
Score where applicable
Restart/New Game button
Clear game-over/win state
Smooth transitions
Haptic-style visual feedback where appropriate
No unnecessary menus

Do not make the games overly complicated.

Visual Design

Use a modern playful arcade aesthetic.

Suggested direction:

Dark or very soft neutral background
Bright accent colors
Rounded cards
Large game icons
Soft shadows
Subtle gradients
Smooth micro-interactions
Large typography
Touch-friendly controls

Give each game its own accent color while keeping the overall design system consistent.

Example:

Tic-Tac-Toe → purple
Hangman → orange
2048 → blue
Memory → pink
Dodge → cyan
RPS → green
Higher or Lower → gold
Brick Breaker → red

Avoid excessive visual effects. The app should feel clean, fast and premium.

Responsive Design

Mobile is the primary target.

Design for:

320px+
375px
390px
430px
Tablet
Desktop

On mobile, use large touch targets and avoid tiny controls.

The home screen should use a 2-column game grid.

On larger screens, the grid can expand while maintaining a reasonable maximum width.

Data Persistence

Use local storage or the platform's simplest local persistence mechanism for:

Best scores
Best streaks
Game statistics where useful

The app should work completely offline after loading.

No login or account should be required.

Architecture

Keep every mini-game isolated into its own component/module.

Suggested structure:

Arcade/Home
TicTacToe
Hangman
Game2048
Memory
Dodge
RockPaperScissors
HigherOrLower
BrickBreaker

Use reusable components for:

Game header
Back button
Score display
Game-over modal
Primary button
Game card
Animations

Avoid duplicating UI logic unnecessarily.

Important

Do not build placeholder versions.

All 8 games must be fully playable.

Prioritize working gameplay and excellent mobile interaction over unnecessary features.

The final result should feel like a small polished mobile arcade app that someone could open and immediately start playing.
